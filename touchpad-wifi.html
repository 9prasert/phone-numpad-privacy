Phone Touchpad · โปรแกรมช่วยบนคอมพิวเตอร์

โปรแกรมช่วยสำหรับ Windows 10 / 11 · Helper for Windows 10 / 11

ติดตั้งโปรแกรมช่วย

แอป Phone Touchpad ส่งการขยับและการพิมพ์ไปยังคอมพิวเตอร์ผ่าน Wi-Fi ในเครือข่ายของคุณ โดยมีโปรแกรมช่วยตัวเล็กนี้ทำงานอยู่บนคอมพิวเตอร์ คอยรับแล้วสั่งเมาส์และคีย์บอร์ดของ Windows

รับจาก Microsoft Store
ฟรี ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ · หรือเปิด Microsoft Store บนคอมพิวเตอร์แล้วค้นหา Phone Touchpad · หน้าเว็บของร้าน

วิธีใช้ครั้งแรก

  1. บนคอมพิวเตอร์ กด "รับ" (Get) ใน Microsoft Store แล้วกด "เปิด" (Open)
  2. ให้มือถือกับคอมพิวเตอร์อยู่ Wi-Fi เดียวกัน หรือให้คอมพิวเตอร์ต่อ Hotspot ของมือถือ
  3. เปิดแอป Phone Touchpad บนมือถือ แอปจะเจอคอมพิวเตอร์เอง แตะ จับคู่
  4. บนคอมพิวเตอร์จะมีหน้าต่างถาม ดูว่าเลข 6 หลักตรงกับบนมือถือ แล้วกด อนุญาต

หลังจากนั้นไม่ต้องทำอะไรอีก โปรแกรมช่วย (รุ่น 1.0.2 ขึ้นไป) เปิดเองทุกครั้งที่เปิดคอมพิวเตอร์ และอยู่ที่ไอคอนข้างนาฬิกา เปิดแอปบนมือถือเมื่อไรก็เชื่อมต่อเอง

ถ้าแอปถามรหัสแทนปุ่ม "จับคู่" แปลว่าแอปหรือโปรแกรมช่วยยังเป็นรุ่นเก่า (การกดอนุญาตใช้ได้ตั้งแต่แอป 1.24 กับโปรแกรมช่วย 1.0.2) ให้ใส่รหัส 8 ตัวที่แสดงในหน้าต่างโปรแกรมช่วย

ความปลอดภัย

ข้อมูลที่ส่งคือการขยับตัวชี้และปุ่มที่กด ทุกแพ็กเก็ตเข้ารหัส (AES-256) ตอนจับคู่ มือถือกับคอมพิวเตอร์สร้างกุญแจร่วมกันและแสดงเลข 6 หลักให้คุณเทียบ แล้วคุณเป็นคนกดอนุญาตบนคอมพิวเตอร์เอง เครื่องอื่นใน Wi-Fi เดียวกันจึงอ่านหรือสั่งคอมพิวเตอร์ของคุณไม่ได้ ข้อมูลส่งตรงระหว่างมือถือกับคอมพิวเตอร์ของคุณภายในเครือข่ายเดียวกันเท่านั้น ไม่ผ่านอินเทอร์เน็ตหรือเซิร์ฟเวอร์ใด กุญแจและชื่อรุ่นของมือถือที่จับคู่ไว้เก็บบนคอมพิวเตอร์แบบเข้ารหัส ผูกกับบัญชี Windows ของคุณ ปุ่ม "ยกเลิกการจับคู่ทั้งหมด" ยกเลิกมือถือทุกเครื่องที่เคยจับคู่

ข้อจำกัด

สั่งหน้าต่างที่เปิดด้วยสิทธิ์ผู้ดูแลระบบ หน้าถามสิทธิ์ (UAC) และหน้าล็อกจอไม่ได้ ต้องใช้เมาส์หรือทัชแพดของคอมพิวเตอร์เองในหน้าเหล่านั้น
ถ้าแอปหาคอมพิวเตอร์ไม่เจอ: ดูว่ามีไอคอน Phone Touchpad ข้างนาฬิกาของ Windows ตรวจว่าอยู่เครือข่ายเดียวกัน (ไม่ใช่ Wi-Fi สำหรับแขก) หรือใส่ IP ของมือถือในช่องล่างของหน้าต่างโปรแกรมช่วย

หยุดหรือเลิกใช้

หยุดชั่วคราว: คลิกขวาที่ไอคอน Phone Touchpad ข้างนาฬิกา แล้วเลือก "ออก"
ไม่ให้เปิดเองตอนเปิดเครื่อง: การตั้งค่า > แอป > เริ่มต้นระบบ
ถอนการติดตั้ง: การตั้งค่า > แอป > แอปที่ติดตั้ง

ทางสำรอง: แบบสคริปต์ไม่ต้องติดตั้ง
ถ้าใช้ Microsoft Store ไม่ได้ ดาวน์โหลด .zip คลิกขวาเลือก "แยกไฟล์ทั้งหมด" แล้วดับเบิลคลิก Start-Touchpad-WiFi.bat หลังเปิดครั้งแรกจะเปิดเองทุกครั้งที่เปิดเครื่อง (เอาออกได้จากช่อง "เปิดเองเมื่อเปิดเครื่อง" ในหน้าต่างโปรแกรมช่วย) ไฟล์ที่ดาวน์โหลดอาจมีคำเตือนความปลอดภัยก่อนเปิด สคริปต์อ่านเนื้อหาได้ทั้งหมด (เปิด PhoneTouchpad-WiFi.ps1 ด้วย Notepad) ถ้าไม่แน่ใจ ไม่ต้องเปิด บนคอมพิวเตอร์ที่เปิด Smart App Control ไว้ Windows จะไม่ยอมให้เปิดไฟล์นี้ ให้ใช้รุ่นใน Microsoft Store การตั้งค่าของแบบสคริปต์อยู่ที่ %APPDATA%\PhoneTouchpad ลบได้เมื่อเลิกใช้

PC helper

The Phone Touchpad app sends your touch and typing to the computer over Wi-Fi on your own network. This small helper runs on the computer, receives them and drives the Windows mouse and keyboard.

Get it from Microsoft Store
Free, no administrator rights · Or open Microsoft Store on the computer and search for Phone Touchpad · Store web page

First-time setup

  1. On the computer, choose "Get" in Microsoft Store, then "Open".
  2. Put the phone and the computer on the same Wi-Fi network, or connect the computer to the phone's hotspot.
  3. Open the Phone Touchpad app on your phone. It finds the computer by itself; tap จับคู่ (Pair).
  4. A window appears on the computer. Check that the 6-digit number matches the one on the phone, then click อนุญาต (Allow).

That is all. The helper (version 1.0.2 or newer) starts by itself whenever you sign in to Windows and sits in the notification area next to the clock; the app connects whenever you open it.

If the app asks for a code instead of showing "Pair", the app or the helper is an older version (pairing by approval needs app 1.24 and helper 1.0.2). Enter the 8-character code shown in the helper window.

Security

What is sent is pointer movement and the keys you press. Every packet is encrypted (AES-256). When pairing, the phone and the computer create a shared key and show you a 6-digit number to compare, and you approve the pairing on the computer yourself, so other devices on the same Wi-Fi cannot read the data or control your computer. Data goes directly between your phone and your computer inside the same network only, never through the internet or any server. The keys and model names of paired phones are stored on the computer encrypted and tied to your Windows account. "ยกเลิกการจับคู่ทั้งหมด" (Unpair all) revokes every phone paired before.

Limitations

It cannot control windows running as administrator, the permission (UAC) prompt, or the lock screen. Use the computer's own mouse or touchpad on those screens.
If the app cannot find the computer: check that the Phone Touchpad icon is in the notification area, that both devices are on the same network (not a guest Wi-Fi), or type the phone's IP address into the box at the bottom of the helper window.

Stopping or removing it

Stop for now: right-click the Phone Touchpad icon next to the clock and choose "ออก" (Exit).
Stop it starting with Windows: Settings > Apps > Startup.
Uninstall: Settings > Apps > Installed apps.

Alternative: the no-install script
If you cannot use Microsoft Store, download the .zip, right-click it, choose "Extract All", then double-click Start-Touchpad-WiFi.bat. After the first run it starts by itself when you sign in to Windows (untick the box in the helper window to stop that). Downloaded files may show a security warning first. The script can be read in full (open PhoneTouchpad-WiFi.ps1 in Notepad); if you are unsure, do not run it. On computers with Smart App Control turned on, Windows will not open it; use the Microsoft Store version. The script's settings are in %APPDATA%\PhoneTouchpad and can be deleted when you stop using it.
