Phone Touchpad · โปรแกรมช่วยบนคอมพิวเตอร์

โปรแกรมช่วยสำหรับ Windows 10 / 11 · Helper for Windows 10 / 11

โปรแกรมช่วยคืออะไร

แอป Phone Touchpad ส่งการขยับและการพิมพ์ไปยังคอมพิวเตอร์ผ่าน Wi-Fi ในเครือข่ายของคุณ โดยมีโปรแกรมช่วยตัวเล็กนี้เปิดไว้บนคอมพิวเตอร์คอยรับแล้วสั่งเมาส์และคีย์บอร์ดของ Windows ตั้งแต่รุ่น 1.23 แอปไม่ใช้ Bluetooth แล้ว จึงต้องมีโปรแกรมช่วยนี้

รับจาก Microsoft Store
ฟรี ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ · ใช้กับแอป Phone Touchpad รุ่น 1.21 ขึ้นไป · แนะนำทางนี้ ติดตั้งได้แม้เปิด Smart App Control และอัปเดตเอง

วิธีใช้

  1. เปิดลิงก์ด้านบนบนคอมพิวเตอร์ กด "รับ" (Get) หรือ "ติดตั้ง" ใน Microsoft Store
  2. เปิด Phone Touchpad Wi-Fi Helper จากเมนู Start จะมีหน้าต่างแสดงรหัสจับคู่ 8 ตัว เปิดหน้าต่างนี้ทิ้งไว้ขณะใช้งาน (ย่อเก็บได้)
  3. ให้มือถือกับคอมพิวเตอร์อยู่ Wi-Fi เดียวกัน หรือให้คอมพิวเตอร์ต่อ Hotspot ของมือถือ
  4. เปิดแอปบนมือถือ แอปจะหาคอมพิวเตอร์เองและถามรหัสจับคู่ (ครั้งแรกครั้งเดียว)

หลังจากนั้นเปิดโปรแกรมช่วยไว้ เปิดแอปเมื่อไรก็เชื่อมต่อเอง

ทางสำรอง: ใช้แบบสคริปต์ไม่ต้องติดตั้ง
ถ้าเปิด Microsoft Store ไม่ได้ ดาวน์โหลด .zip คลิกขวาเลือก "แยกไฟล์ทั้งหมด" แล้วดับเบิลคลิก Start-Touchpad-WiFi.bat ไฟล์ที่ดาวน์โหลดอาจมีคำเตือนความปลอดภัยก่อนเปิด สคริปต์อ่านเนื้อหาได้ทั้งหมด (เปิด PhoneTouchpad-WiFi.ps1 ด้วย Notepad) ถ้าไม่แน่ใจ ไม่ต้องเปิด บนคอมพิวเตอร์ที่เปิด Smart App Control ไว้ Windows จะไม่ยอมให้เปิดไฟล์นี้ ให้ใช้รุ่นใน Microsoft Store

ความปลอดภัย

ข้อมูลที่ส่งคือการขยับตัวชี้และปุ่มที่กด ทุกแพ็กเก็ตเข้ารหัส (AES-256) และตรวจตัวตนด้วยรหัสจับคู่ เครื่องอื่นใน Wi-Fi เดียวกันอ่านหรือสั่งคอมพิวเตอร์ของคุณไม่ได้ถ้าไม่รู้รหัส ข้อมูลส่งตรงระหว่างมือถือกับคอมพิวเตอร์ของคุณภายในเครือข่ายเดียวกันเท่านั้น ไม่ผ่านอินเทอร์เน็ตหรือเซิร์ฟเวอร์ใด รหัสจับคู่บนคอมพิวเตอร์เก็บแบบเข้ารหัสผูกกับบัญชี Windows ของคุณ ปุ่ม "สร้างรหัสใหม่" ยกเลิกมือถือที่เคยจับคู่ทั้งหมด

ข้อจำกัด

ทาง Wi-Fi สั่งหน้าต่างที่เปิดด้วยสิทธิ์ผู้ดูแลระบบ หน้าถามสิทธิ์ (UAC) และหน้าล็อกจอไม่ได้ ต้องใช้เมาส์หรือทัชแพดของคอมพิวเตอร์เองในหน้าเหล่านั้น
ถ้าแอปหาคอมพิวเตอร์ไม่เจอ: ตรวจว่าอยู่เครือข่ายเดียวกัน (ไม่ใช่ Wi-Fi สำหรับแขก) หรือใส่ IP ของมือถือในช่องล่างของหน้าต่างโปรแกรมช่วย

เลิกใช้

รุ่น Microsoft Store: ถอนการติดตั้งจาก การตั้งค่า > แอป · แบบสคริปต์: ปิดหน้าต่างโปรแกรมช่วยแล้วลบโฟลเดอร์ที่แยกไฟล์ไว้ การตั้งค่าของโปรแกรมช่วยอยู่ที่ %APPDATA%\PhoneTouchpad ลบได้เช่นกัน

PC helper

The Phone Touchpad app sends your touch and typing to the computer over Wi-Fi on your own network. This small helper runs on the computer, receives them and drives the Windows mouse and keyboard. From version 1.23 the app no longer uses Bluetooth, so the helper is required.

Get it from Microsoft Store
Free, no administrator rights · Works with Phone Touchpad 1.21 or newer · Recommended: installs even with Smart App Control on, and updates itself

How to use

  1. Open the link above on your computer and choose "Get" or "Install" in Microsoft Store.
  2. Open Phone Touchpad Wi-Fi Helper from the Start menu. A window shows an 8-character pairing code. Keep this window open while you use the app (you can minimise it).
  3. Put the phone and the computer on the same Wi-Fi network, or connect the computer to the phone's hotspot.
  4. Open the app on your phone. It finds the computer by itself and asks for the pairing code (first time only).

After that, keep the helper running and the app connects whenever you open it.

Alternative: the no-install script
If you cannot use Microsoft Store, download the .zip, right-click it, choose "Extract All", then double-click Start-Touchpad-WiFi.bat. Downloaded files may show a security warning first. The script can be read in full (open PhoneTouchpad-WiFi.ps1 in Notepad); if you are unsure, do not run it. On computers with Smart App Control turned on, Windows will not open it; use the Microsoft Store version.

Security

What is sent is pointer movement and the keys you press. Every packet is encrypted (AES-256) and authenticated with the pairing code, so other devices on the same Wi-Fi cannot read it or control your computer without the code. Data goes directly between your phone and your computer inside the same network only, never through the internet or any server. The pairing code on the computer is stored encrypted and tied to your Windows account. "New code" revokes every phone paired before.

Limitations

Over Wi-Fi the app cannot control windows running as administrator, the permission (UAC) prompt, or the lock screen. Use the computer's own mouse or touchpad on those screens.
If the app cannot find the computer: check both are on the same network (not a guest Wi-Fi), or type the phone's IP address into the box at the bottom of the helper window.

Removing it

Store version: uninstall it from Settings > Apps. Script version: close the helper window and delete the extracted folder. The helper's settings are in %APPDATA%\PhoneTouchpad and can be deleted too.
