Phone Touchpad - Wi-Fi helper for Windows 10 / 11
==================================================

1. Double-click  Start-Touchpad-WiFi.bat
   A window opens and shows an 8-character pairing code. Keep it open while you use the app.
2. Put the phone and this computer on the same Wi-Fi (or connect this computer to the phone's hotspot).
3. In the Phone Touchpad app (1.21 or newer): Menu -> Wi-Fi mode -> turn on, then enter the pairing code.

No installation and no administrator rights are needed. Closing the window stops the helper.
Help and details: https://9prasert.github.io/phone-numpad-privacy/touchpad-wifi.html


Phone Touchpad - โปรแกรมช่วยโหมด Wi-Fi สำหรับ Windows 10 / 11
==================================================

1. ดับเบิลคลิก  Start-Touchpad-WiFi.bat
   จะมีหน้าต่างแสดงรหัสจับคู่ 8 ตัว เปิดทิ้งไว้ขณะใช้งาน
2. ให้มือถือกับคอมพิวเตอร์เครื่องนี้อยู่ Wi-Fi เดียวกัน (หรือให้คอมพิวเตอร์ต่อ Hotspot ของมือถือ)
3. ในแอป Phone Touchpad (รุ่น 1.21 ขึ้นไป): เมนู -> เชื่อมผ่าน Wi-Fi -> เปิดใช้ แล้วใส่รหัสจับคู่

ไม่ต้องติดตั้ง ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ ปิดหน้าต่าง = หยุดทำงาน
วิธีใช้และรายละเอียด: https://9prasert.github.io/phone-numpad-privacy/touchpad-wifi.html
